# CalaPlayerSrcmBuilder **v1.1.0**

> 一站式素材打包工具：把图片/音乐丢进文件夹，一键生成可在 **CalaPlayer** 里使用的静态补丁。
> **只往补丁容器里追加，绝不替换任何原生条目**；随时一键卸载回滚。

## ✨ v1.1.0 有什么新东西

| | 说明 |
|---|---|
| 🖼️ **背景保持 2560×1440（路线 B）** | 背景贴图不再被压到 1920×1080：整块重建 cooked 贴图，**2560×1440 的源图一个像素都不重采样**。实测 PSNR `mixueer_00044` 35.5 → **37.0 dB**、`城市夜景` 41.1 → **41.7 dB** |
| 🎞️ **时间轴与右侧预览块终于显示你的背景** | 把每个新背景的 250×141 缩略图**追加进游戏自己的预览图集**（末尾空闲格，序号 165 起），并让该背景的预览材质指向那一格——游戏自己会把坐标传给时间轴单元格和右侧「Background」预览块。**纯静态、不需要常驻注入**。因此**背景上限 = 59**（图集空闲格数） |
| 🏷️ **下拉缩略图修复** | 每个新背景自动生成配套预览材质 `MI_<名字>`（挂在背景表对应行的预览引用上），下拉里的小图从此是你自己的图。留了 `-NoThumb`（不造 MI）与 `-NoAtlas`（不做图集追加）两个诊断开关 |
| 📐 **宽高比约束（防拉伸）** | 宽 > 高一律放行（非 16:9 只提示）；竖屏与正方形默认**拒绝打包**并给中文提示；`-Fit contain` 会居中补黑边后放行 |
| ✅ **判据加强** | 回归 **29 场景**；新增 A8（缩略图通道）、A9/A9b（图集差异块与原生格像素差，mip0 必须 0）、A10（预览材质是原生形态）、**T29（`-Combined` 在上一轮成果上再加背景）**；A6 把重建/追加后的资产**用 UE 解析器读回**（尺寸/格式/13 级 mip/每级哈希）。路线 B 与图集的几个"假绿"坑都已被判据挡住 |
| 🔧 **`-Combined` 累积修好了** | 之前"在上一轮已经加过行的成果上继续累积"会失败（`da-patch` 重新序列化让表多出一行而行数不变，被 L3 尾部门拒绝）。现在累积模式**基线换回游戏原生表**，上一轮的行走字节级重新追加 ⇒ 可以在已有成果上继续加背景/音频；T29 专门守这条 |

| 🧭 **新手引导只弹一次（真修好了）** | 之前引导每次启动都弹：不只是 localStorage 按随机端口分桶，还因为**打包自检会把用户的「看过引导」标记清掉**（它用「清标记再造首次运行」的办法，还原时会把原本为空的设置文件删掉）。现在引导**一显示就记标记**、自检改在临时目录里操作 ⇒ 只在第一次弹，想再看点右上角「引导」按钮 |

## 🚀 三步用起来

1. 建一个素材夹，里面放 `bg\`、`BGM\`、`Sound\`、`Ambient\` 四个子目录（大小写不敏感，缺哪个跳过哪个）；
2. 打开 GUI → 选「游戏 Paks 目录」和「素材根目录」→ 点「开始打包」；
3. **关掉游戏**，进 `out_patch\` 跑 `install.ps1`（或右键「在终端中运行」）→ 打开游戏进 Create 就能看到你的素材。

回滚：同一个目录里跑 `uninstall.ps1`，一键回到安装前状态。

## 🧭 已知边界（请先读）

* **时间轴单元格**与编辑器右侧的**「Background」预览块**：**本版起会显示你新增的背景**（纯静态实现，
  见上面第 2 条）。
* **下拉列表里的小缩略图锐度会轻微降低（约 30%）**：由于游戏原生渲染机制（该缩略图只从图集里那一格
  采样，且 GPU 的 mip 选择落在两级的混合上），列表小图会比旧版略软一点——**肉眼无感**，
  这是换取时间轴与预览块完整显示的合理妥协。不想要这个取舍可以加 `-NoAtlas` 回到旧行为。
* **背景上限 = 59**（图集空闲格数）；超过要 `-Force`，且超出的背景缩略图不会显示。
* **不受影响**：背景下拉列表的内容、主菜单章节封面、以及**游戏画面里的背景本体**都是你自己的图。
* 运行时补救方案（R2）**已废弃**（需 Frida 常驻、严重卡顿、重启即失效，作者也确认所用引擎接口
  不是预期路径）；现行方案就是上面的静态图集追加。
* **安装前必须先关掉游戏**（`.ucas` 被占用会导致安装失败）。
* Windows 可能提示「未知发布者」：exe 未签名，点「更多信息 → 仍要运行」即可。
* 路径建议用**纯英文**；你需要先拥有 **CalaPlayer 游戏本体**。

## 🔬 质量与安全（怎么证明它没坏）

* 每次打包都跑 **A0~A10** 判据：三个壳（贴图 / 音频 / MI）写回逐字节保真、容器里能读回每个新资产、
  音频解回 WAV 与源逐字节一致、chunk id 台账（新包 0 命中 + 4 张 DA 与图集这 5 个"故意覆盖"）、
  四张数据表的新行 FName 可解析、缩略图通道指向我们自己的材质、**图集差异块 ⊆ 我方格子**
  （且原生 165 格在 mip0 像素改动 = 0）、预览材质是原生形态；图像类还会打印
  `QUALITY: PSNR / MAE / 清晰度比`。
* **29 场景回归全绿**；GUI 侧另有 API 验收与冻结 exe 验收（70+ 项）。
* 只往补丁容器里追加：原生容器**永不写入**，装前把已装容器移到 `_prev_container\`，
  `uninstall.ps1` 只删我们自己产物、还原备份。
